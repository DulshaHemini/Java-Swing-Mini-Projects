A collection of small Java Swing projects that I am building while learning desktop GUI development step by step.

The main purpose of this repository is to improve my understanding of **Java Swing**, event handling, layouts, input validation, and GUI design before moving on to larger applications such as my university **UniMIS project**.

## Mini Projects

### 1. Click Counter

A simple Java Swing application that increases a counter whenever a button is clicked.

**Features**
- Display a counter
- Increase the count when a button is clicked
- Practice basic event handling

**Concepts Used**
- `JFrame`
- `JPanel`
- `JLabel`
- `JButton`
- `ActionListener`

---

### 2. Simple Calculator

A beginner-friendly calculator built using Java Swing.

**Features**
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Invalid input handling
- Clear button

**Concepts Used**
- `JFrame`
- `JPanel`
- `JLabel`
- `JTextField`
- `JButton`
- `ActionListener`
- `getText()`
- `setText()`
- `try-catch`
- Input validation
